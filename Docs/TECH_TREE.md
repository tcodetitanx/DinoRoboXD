# DINO ROBO XD — Tech Tree

Research at the **Lab** (T2+; T1 techs research at the Workbench). Each tech costs
resources (consumed on start) + time. One research at a time. Sprite badges use itm_*.

## Era 0 — Crash Site (free, tutorial-implicit)
- start unlocked: hq, stockpile, fire_pit, leanto, hand_crank, drone_pad, hauler_bot,
  recon_quad, chop/mine by hand (player avatar), palisade.
